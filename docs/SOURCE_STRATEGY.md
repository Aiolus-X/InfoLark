# 资讯来源与筛选策略

目标是尽可能广泛发现前一天的创业/融资与 AI 商业信息，覆盖中国和海外，统一中文整理。每条重点内容提供可点开的来源链接。不是用固定网站清单声称覆盖整个互联网。

## 三层重点与来源

| 层级 | 筛选标准 | 重点渠道 |
| --- | --- | --- |
| 个人 / 小团队 | 可复现性：可承担成本、明确交付物、可复测流程、获客路径及前提 | Product Hunt、Show HN、Indie Hackers 收入案例、V2EX/w2solo、出海、套壳应用、垂直工具、创始人公开帖 |
| 初创 / 有一定规模 | 价值性：真实问题、产品与商业价值、客户验证、壁垒；不只看融资额 | TechCrunch、VentureBeat、36氪、创业邦、IT桔子公开资料、YC 最新公司/Launch HN、机器之心、量子位、Crunchbase、Sifted、Tech.eu 等 |
| 大厂 / 企业 | 影响力：是否改变创业机会、产业成本、采购、渠道或竞争格局 | OpenAI、Anthropic、Google、Meta、字节、阿里等官方发布及公开报道；a16z、红杉/HongShan、Sequoia 研究；平台 API 重大变化 |

每层最多 5 条，不设最低数；同一事件的转载与不同语言报道合并。融资计划、已完成融资、估值、收入、ARR、利润分别表达。个人案例的收入和经营数据标明自报口径，不当作普通人一定能复制的结果。

## 采集结构

1. **站点源**：RSS/Atom、企业/投资机构公开发布，以及 Product Hunt 产品流。
2. **社区源**：HN 公开搜索 API 获取 Show HN 和 Launch HN，保留发布时间及原帖。
3. **全网发现**：按中英文创业、融资、独立开发、收入、商业化、平台变更等主题查询 Google News 与公开网页搜索；不限制所有结果必须来自名单内站点。
4. **定向补充**：对重点媒体、社区与公司做额外搜索，解决 RSS 条目有限或站点没有有效 RSS 的问题。
5. **原文定位**：尽量从聚合索引找到发布者原文，提取日期和可读正文。无法取到全文的保留为线索，不编造详细经营拆解。
6. **可选增强**：配置 `BRAVE_SEARCH_API_KEY` 使用 Brave 搜索；配置 `X_BEARER_TOKEN` 使用 X recent search。没有这些 Key 时仍运行其他公开源。

默认源清单在 `sources.json`。当前配置为 24 个站点流、2 类 HN 查询、37 组中英文主题/定向查询；后者分别尝试新闻与网页搜索，共 100 个源/查询任务。这个数字是任务数，不是“100 家网站”，也不是全网覆盖率。

## 日期与完整性

- 日报覆盖北京时间前一天 00:00–23:59，不使用“当前时间往前滚动 24 小时”混淆日期。
- 发布者页面的原始发布日期优先；可信 RSS/社区时间可作为依据。泛网页搜索结果的收录时间不直接当作新闻发布时间。
- 事件发生日期单独记录；昨日报道可能讨论较早发生的事件，必须明说。
- 采集滚动保留候选。首次运行只能用当时可取得的历史数据，不能宣称已监测完整的一天。
- 原始抓取数包含历史 feed 条目；筛选后的“目标日线索数”才是当天候选量。

## 内容与证据

模型只接收真实获取的证据。每条事实必须引用候选库中的来源 ID，并提供能在对应正文找到的逐字片段用于内部校验。公开日报写摘要和链接，不复制整篇文章。建议和推论标注为“分析”，并给适用前提或验证动作。

未进入主文的合格资讯放在“更多线索索引”，保留来源标题以便核对；不把未阅读全文的索引条目混为已验证案例。主文统一中文，经营数据缺失时明确说明，不自动补“零融资”“单人开发”或虚构获客渠道。

## 必须显示的覆盖缺口

- **X/Twitter**：公开索引不能代表完整时间线。无 X API 时明确说明只做公开发现；接口结果也受查询、权限及分页限制。
- **IT桔子等数据平台**：只用可公开访问资料；登录后数据、付费库未取得授权就不接入，不绕过访问限制。
- **The Information**：公开转述单独标注，不把转述写成已读付费原文。
- **HTTP 403/429/5xx、验证码或失效 feed**：记录失败，不换身份/代理绕过，也不把 HTML 登录页当 RSS。
- **旧源**：新浪旧 RSS 实测停留在历史年份，已不用它来代表新财经资讯；对应渠道走公开搜索发现。

每份日报附来源状态、返回条数、目标日条数及覆盖缺口。Google News 的原文跳转使用公开页面提供的数据，属于可能变化的浏览器兼容路径；失败时只保留索引。参考实现行为来自 [google-news-url-decoder](https://github.com/SSujitX/google-news-url-decoder)，不使用登录 Cookie。
